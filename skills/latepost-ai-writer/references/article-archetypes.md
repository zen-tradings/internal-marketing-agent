# 稿型路由

## 选择顺序

按主要证据和读者问题路由，不按标题包装路由：

1. 有可发布的新事实、速度优先：独家快讯。
2. 同期有多个事件，需要说明共同趋势：AI 月报与趋势综合。
3. 核心材料是 AI 创始人的系统访谈：AI 创业访谈。
4. 核心问题是 AI 安全、责任或人与技术的关系：AI 议题观察。
5. 研究一家公司、组织、竞争格局或产业链：公司与产业深描。
6. 核心材料来自研究者、投资人或职业经理人访谈：人物对话。
7. 主要任务是解释技术机制与路线：技术解释。
8. 有可复现的亲自测试记录：产品实测。

同时满足多类时，问“哪种证据承担核心结论”。例如，创始人接受采访但文章主要靠供应链调查推进，应写公司与产业深描；一次发布会附简单体验，不足以写产品实测。

## 独家快讯

- 可分析语料中位约 1550 字，通常没有小标题。
- 第一段直接交代主体、动作、时间、关键数字和信息状态。
- 第二至四段补来源边界、交易或人事结构及当事方回应。
- 后半部分只保留理解影响所需的历史、竞争和业务数据。
- 结尾说明改变了什么、仍有哪些条件未满足。
- “独家”“据我们了解”只能来自用户提供的真实核实材料。

融资稿分别写清融资轮次、融资额、投前/投后估值、老股交易和资金用途。人事稿分别写清原职位、新职位、汇报线、实际职责和到岗状态。

## 公司与产业深描

- 可分析语料中位约 5860 字，常见 3 个小标题。
- 导语给关键变化，再建立旧基线和核心矛盾。
- 常用推进：变化 → 旧路径为何失效 → 新策略/组织 → 竞争验证 → 未决约束。
- 并行比较公司时使用相同维度：人才、投入、模型、产品、客户、收入。
- 将战略落到预算、人员流动、汇报关系、研发节点、客户和成本上。

组织竞争稿不能把人才数量直接等同于模型实力。至少串起“人员/组织动作 → 资源投入 → 技术或产品结果 → 市场反馈”中的三环。参考 2904、2891、2897。

具身和智驾产业稿分别标出演示、试点、部署、量产、付费和规模化状态，并检查安全边界、人工介入和单位经济性。参考 3017、2939、2691。

## 人物对话

- 可分析语料中位约 9754 字，常见 3 个主题章节。
- 叙事导语交代人物路径、当前成绩、非共识选择和访谈价值。
- 问题按认知推进：事实与背景 → 技术/产品判断 → 商业与竞争 → 长期动机。
- 每次只追一个矛盾；追问基于上一回答的数字缺口、代价或反例。
- 保留判断和人物节奏，删除口头重复，不能替受访者补观点。

适合研究者、投资人、职业经理人和非创业主题访谈。创始人访谈若主要讨论公司从 0 到 1、PMF、融资与商业化，改用“AI 创业访谈”。

## 技术解释

- 当前可分析样本较少，中位约 6907 字、3 个小标题，只把统计当方向。
- 用最近的变化回答“为什么现在值得解释”。
- 每个概念依次回答：解决什么、与旧方案差在哪、代价是什么、谁受影响。
- 每条路线比较目标、机制、成本、限制、适用条件和代表团队。
- 将技术变化连接到产品体验、组织分工、算力成本或市场权力。
- 争议未形成共识时并列证据，不替行业宣布终局。

模型榜单、参数规模和一次公开演示都不是产品结论。必须补任务、数据、环境、成本和失败条件。

## 产品实测

- 可分析语料中位约 8130 字、3 个小标题。
- 开头给真实任务、测试对象、版本和范围，不先复述发布会卖点。
- 明确设备、账号、网络、提示词、工具权限和人工介入。
- 按任务组织正文，同时记录成功、失败、波动和不可复现结果。
- 对比旧流程或竞品时保持相同条件。
- 结尾判断改变了什么，以及模型、权限、生态或成本中的主要约束。

把“内部基准、公开评测、记者实测、真实用户使用”分开。一次成功只能证明“在该条件下完成过”，不能写成稳定能力。

## AI 月报与趋势综合

- 可分析语料中位约 1.19 万字，常见 6–7 个小标题。
- 先列出当期 2–4 个真正改变判断的主题，不按发布日期堆新闻。
- 每个主题使用同一结构：触发事件 → 技术或商业机制 → 公司/市场后果 → 反证与未知。
- 同一主题至少连接两个独立事件或数据点，才足以称为趋势。
- 投融资板块区分融资活跃、估值变化与真实收入，不用资本热度替代需求。
- 结尾说明相较上一周期，哪些判断被强化、推翻或仍待观察。

播客材料也按议题重组，不按谈话时间线誊写。引语只保留非共识判断、关键事实和有价值的分歧。参考 2898、2966、3103。

## AI 创业访谈

- 可分析语料中位约 1.05 万字，常见 3 个主题章节。
- 导语先用产品、用户、收入、融资或失败经历证明“为什么值得谈”。
- 迅速提出公司最危险的矛盾：模型挤压、获客成本、留存、定价、交付或组织能力。
- 问答依次验证：问题与 PMF → 技术/产品选择 → 增长和商业化 → 竞争与生存 → 创始人动机。
- 对 ARR、合同额、付费用户和融资分别追问口径、时间、复购与确认方式。
- 不把创始人的宏大愿景写成记者结论；用反例、成本和下一阶段约束检验。

推荐“叙事前言 + 追问式问答”，但前言不能提前替受访者赢得争论。参考 3658、3078、3025、2852。

## AI 议题观察

- 当前可分析样本 3 篇，中位约 8822 字、4 个小标题，作为审慎的扩展稿型。
- 从具体事故、研究发现或人物处境进入，不从“人类未来”起笔。
- 结构为：事件与风险 → 概念机制 → 相反证据/不同立场 → 对人的具体后果。
- 清楚区分实验现象、研究者解释、伦理判断和作者推论。
- 医疗、安全、心理和社会影响结论说明样本、适用条件和争议。
- 结尾回到人或制度需要承担的选择，不用无证据的文明尺度金句。

适合 AI 对齐、欺骗、安全责任、技术焦虑与人的主体性。参考 3086、2947、2894。
