# 全资产宏观编辑方法

## 核心结构

这套方法的核心不是术语或语气，而是连续完成五次区分：

1. 已发生事实与作者推断。
2. 市场共识与价格已经反映的程度。
3. 新信息与旧叙事之间的增量。
4. 同一冲击在不同时间尺度上的相反影响。
5. 基准路径与能够推翻它的反向路径。

## 标题与开头

标题应承诺正文真正回答的问题。优先使用对象或变化加上矛盾、落差、机制或后果；问句只在正文能给条件化答案时使用。不要复制参考账号的夸张感叹、战绩宣称或省略号习惯。

开头在数段内完成：给判断、指出异常、说明市场原先在想什么、提出决定后文的关键变量。宏观常识、事件时间线和机构观点都放到它们第一次解释判断的位置。

## 定价与共识

“市场已经定价”必须有可复核依据，例如期货隐含路径、收益率曲线、期权指标、调查、一致预期、资金流或明确价格行为。只有新闻热度时，改写为“主流叙事倾向于”，并明确它不是持仓或价格证据。

避免把资产上涨简单解释为“风险偏好改善”。先检查利率、美元、盈利预期、流动性、供需、期限溢价、风险溢价与被动资金等候选路径。

## 传导链

使用可检查的中间变量，而不是从事件直接跳到资产结论。常见链条包括：

- 财政或货币政策 → 实际利率/期限溢价/流动性 → 汇率与估值 → 风险资产。
- 经济数据 → 增长与通胀概率 → 央行路径 → 曲线与美元 → 股票、黄金、信用。
- 地缘冲击 → 实物流/保险/库存/运输 → 商品价格 → 通胀与利润率 → 汇率和股票。
- 仓位或微观结构 → 流动性与被迫交易 → 短期价格 → 是否反馈到基本面。

每条链说明方向、时间、可能中断的位置和最敏感的观察指标。

## 情景与失效

基准情景不是“最有信心的故事”，而是当前证据下最少额外假设的路径。反向情景必须能真实改变结论，不能只是“情况也可能不同”。

失效条件使用可观察变化，例如数据路径、政策动作、曲线、相对价格、供需或风险溢价，而不是把作者感受当作信号。具体点位只能作为观察线，不得转换为交易命令。

## 跨资产

先找共同驱动，再解释背离。不要认为股票、债券、美元、黄金、油或数字资产永远保持固定关系。说明当前主导的是增长、通胀、流动性、信用、供需还是尾部对冲，并写出主导因子切换的信号。

默认采用全球框架，优先解释中美政策、美元体系和主要发达市场如何向全球资产传导；只有任务相关时扩展到其它地区。

## 语言与节奏

- 使用短段落承载高密度判断，长段落只用于完整机制链。
- 允许中英文市场术语并存，但首次出现时保证读者能理解其作用。
- 使用“这意味着”“关键不在于”“更重要的是”时，后句必须改变读者判断。
- 用自然语言表达置信边界：已确认、较可能、我们的判断、尚待验证。
- 删除战绩式自证、社群引流、个人交易复盘和参考账号免责声明；Zen 模板承担固定品牌与合规内容。

## 译编与外部观点

译编类样本只提供三项编辑启示：开头说明来源与价值、先提炼中心命题、在长文中设置清晰导航。不得把被翻译作者的观点、句法、故事或交易哲学当成 Zen Trading 的原创方法。
