# 宏观策略交稿检查

## 发布阻断项

出现任一项即停止交稿或删除相关内容：

- 核心事实没有直接的一手/原始来源，且文章仍给出确定性核心判断。
- 实时价格、收益率、估值、共识、资金流或仓位无法追溯到素材。
- 把机构观点、市场传闻或作者推断写成已证实事实。
- 情景中新增素材没有支持的政策、数字、事件或资产结论。
- 出现买入、卖出、目标价、入场、退出、止损、仓位或个性化交易指令。
- 表格中的任一数字缺少口径、时点或来源。
- 标题强于正文证据，或声称代表参考账号、复刻参考原句和独特标题。

## Slack 待复核提醒

以下问题不阻断草稿，但必须在原任务 Slack 线程提醒，供人工发布前复核：

- 高风险因果或跨资产推断没有充分限定，或没有明确标为“我们的判断”。
- 中低置信度审计认为关键表述可能过强，但现有证据不足以确定性改写。
- 反向情景、观察信号或失效条件属于合理推演，但来源只能支持其前提而不能直接证明结论。

这些提醒可以保留正文原句；不得把推断冒充为来源已经证实的事实。关键数字、市场定价或市场反应如保留，直接证据应优先进入文末精选来源。

## 五项评分

每项内部评分 0–2；总分低于 8 时继续编辑，但不要在公开稿展示评分。

1. 证据边界：事实、外部观点与作者判断是否清楚分层。
2. 预期差：是否说清市场原有认知和新信息的真正增量。
3. 传导完整：是否包含中间变量、时间尺度和可能中断点。
4. 双向验证：是否有真实反向情景、观察信号和失效条件。
5. 可读与克制：是否结论先行、自然推进、无喊单和空洞修辞。

## 稿型检查

- 快评：动态事实优先在最近 48 小时；篇幅与证据量匹配。
- 深度：旧资料明确标注时点；历史类比说明关键差异。
- 周报：动态资料优先最近七天；不是逐条新闻摘要。
- 所有稿型：文末只保留精选来源，不堆积无关链接。
