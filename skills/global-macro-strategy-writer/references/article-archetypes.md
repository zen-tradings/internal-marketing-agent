# 宏观策略稿型

## 选择顺序

1. 用户明确说快评、点评、盘中、盘后、数据公布、会议结果或单一事件影响时，选“事件快评”。
2. 用户要求解释机制、周期、政策组合、跨资产关系、框架或长期路径时，选“机制型深度”。
3. 用户要求周报、周度回顾、下周展望或一周多资产总结时，选“宏观周报”。
4. 同时命中多个稿型时，按用户最终要解决的问题选择一个；不要拼接多个固定模板。
5. 无法判断时，默认“机制型深度”。

## 事件快评

目标篇幅：800–1,500 字。

完成以下认知顺序，不必把它们写成固定栏目：

1. 发生了什么，以及市场第一反应是什么。
2. 结果相对预期真正改变了什么。
3. 哪条传导路径最重要，哪些资产反应可能只是噪音。
4. 接下来观察一至三个指标或事件。
5. 什么情况会推翻当前解释。

开头直接给核心判断。背景只保留解释预期差所必需的部分。单一来源只能支持该来源可证明的事实，不能自动证明整个市场因果。

## 机制型深度

目标篇幅：2,000–4,000 字。

常用推进弧线：异常或争议 → 市场隐含假设 → 机制拆解 → 跨资产传导 → 基准与反向情景 → 验证指标。

至少回答：

- 当前主流叙事遗漏了什么变量或时间尺度；
- 传导发生在哪个环节，为什么不会直接一步到位；
- 哪些资产表达的是同一个因子，哪些表面相关但驱动不同；
- 最强反例是什么；
- 未来什么数据、价格行为或政策动作会验证或证伪。

不要用历史类比替代机制。历史比较必须说明当时与现在的相同点和关键差异。

## 宏观周报

目标篇幅：2,500–4,500 字。

周报不是新闻清单。先确定一条统领全周的变化，再将资产表现组织成同一套传导关系：

1. 本周改变判断的两至四件事。
2. 利率、汇率、股票、商品、信用、波动率或数字资产之间的一致与背离。
3. 市场已经消化的部分和尚未消化的尾部。
4. 下周最重要的催化剂、可观察指标和反向风险。

动态事件优先使用最近七天的信息。结构性资料可以更早，但必须标明时点，不得包装成当周新信息。
